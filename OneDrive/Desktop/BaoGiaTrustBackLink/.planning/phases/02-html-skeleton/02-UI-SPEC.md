## Telegram Deeplink Specification (CTA-03, CTA-04)

### Pattern

Every Telegram link in this document uses a dual-target strategy:

```
Primary href:   tg://resolve?domain=trustbacklink&text={pre-filled-message}
Fallback attr:  data-fallback="https://t.me/trustbacklink?text={pre-filled-message}"
```

JavaScript in Phase 2 is NOT used to switch between primary/fallback. The `data-fallback` attribute is a contract for Phase 5 (GSAP/JS phase) to wire the onclick handler. In Phase 2 skeleton, the primary `href` is sufficient for markup purposes.

### Pre-filled Message Format

```
Tôi+muốn+mua+gói+{ServiceName}+{TierName}+{Quantity}
```

URL-encoded Vietnamese text. No raw Unicode in the URL — use `+` for spaces, percent-encode accented characters.

## Accessibility Contract

| Element | Required Attribute | Value |
|---------|-------------------|-------|
| `<html>` | `lang` | `vi` — already set in Phase 1 |
| Logo `<img>` | `alt` | `TrustBackLink logo` |
