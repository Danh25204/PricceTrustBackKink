<objective>
Place the `.nojekyll` file at the repo root and verify the full GitHub Pages deployment pipeline: push the Phase 1 artifacts, confirm the live URL loads, and confirm `base.css` and the Google Fonts link resolve without 404s.

Purpose: Without `.nojekyll`, GitHub Pages runs Jekyll on every push. Jekyll silently excludes underscore-prefixed files and dotfiles from the build output — future phases may add such files, and fixing this retroactively requires a force-push or branch rebuild. Placing `.nojekyll` before the first meaningful push is zero-cost and eliminates the risk permanently.

Output: `.nojekyll` at repo root. A confirmed-live GitHub Pages URL that loads `index.html` without errors.
</objective>
