## Spacing Scale

Declared values (multiples of 4 only). Phase 1 establishes these as CSS custom properties in `base.css`; they are consumed by layout and component CSS in later phases.

| Token | Value | CSS Custom Property | Usage |
|-------|-------|---------------------|-------|
| xs | 4px | `--space-xs: 4px` | Icon gaps, inline padding |
| sm | 8px | `--space-sm: 8px` | Compact element spacing |
| md | 16px | `--space-md: 16px` | Default element spacing |
| lg | 24px | `--space-lg: 24px` | Card internal padding |
| xl | 32px | `--space-xl: 32px` | Layout gaps |
| 2xl | 48px | `--space-2xl: 48px` | Major section breaks |
| 3xl | 64px | `--space-3xl: 64px` | Page-level section spacing |

Exceptions:
- Floating Telegram CTA button minimum touch target: 56×56px (REQUIREMENTS.md CTA-01 — "56×56px tối thiểu"). This is a Phase 2/3 implementation detail; the token `--cta-touch: 56px` is declared here in Phase 1.

## Typography

All sizes are CSS custom properties declared in `base.css`. `font-display: swap` is mandatory on all `@font-face` declarations (ARCHITECTURE.md mobile rule 3).

| Role | Size | CSS Property | Weight | Line Height | Font Family | Source |
|------|------|--------------|--------|-------------|-------------|--------|
| Body | 16px | `--text-body: 16px` | 400 (regular) | 1.6 | Be Vietnam Pro | Default + Vietnamese market legibility |
| Label / Small | 13px | `--text-label: 13px` | 400 (regular) | 1.4 | Be Vietnam Pro | Card metadata, per-unit price |
| Subheading | 20px | `--text-sub: 20px` | 600 (semibold) | 1.3 | Be Vietnam Pro | Card title, section subheads |
| Heading | 28px | `--text-heading: 28px` | 700 (bold) | 1.2 | Playfair Display | Section headings (`<h2>`) |
| Display | 40px | `--text-display: 40px` | 700 (bold) | 1.1 | Playfair Display | Hero `<h1>` tagline |

Weights declared: 400 (regular) and 600/700 (semibold/bold). Two weights only per font family. Be Vietnam Pro uses 400 + 600; Playfair Display uses 700 only.

Google Fonts import pattern (to be placed in `base.css`):
```
https://fonts.googleapis.com/css2?family=Playfair+Display:wght@700&family=Be+Vietnam+Pro:wght@400;600&display=swap&subset=vietnamese
```

## Z-Index Stack

Declared in `base.css` to prevent layering conflicts across all phases.

| Layer | Value | CSS Custom Property | Element |
|-------|-------|---------------------|---------|
| Canvas background | 0 | `--z-canvas: 0` | Three.js `<canvas>` |
| Dark overlay | 1 | `--z-overlay: 1` | `rgba(0,0,0,0.65)` overlay div |
| Content | 2 | `--z-content: 2` | All text sections, pricing cards |
| Floating button | 100 | `--z-float: 100` | Sticky Telegram floating CTA |
| Modal / overlay | 200 | `--z-modal: 200` | Reserved (not used in v1) |

Source: CLAUDE.md critical rules; REQUIREMENTS.md PERF-01; ARCHITECTURE.md canvas positioning.
