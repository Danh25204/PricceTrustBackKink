# Plan 05-01: GSAP Integration — Ticker Wiring + Hero Animation

## Objective

Replace the temporary `requestAnimationFrame` loop in `index.html` with GSAP's ticker (PERF-06). Load GSAP + ScrollTrigger via CDN. Write `assets/js/main.js` as the Phase 5 entry point that inits the Three.js scene, wires `gsap.ticker.add(render)`, and triggers the hero load animation (ANIM-01).

## Context

Phase 4 left a temporary RAF loop in `index.html` with a `// TODO Phase 5` comment:

```
function loop() {
  render();
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);
```

This must be removed. GSAP's ticker becomes the sole render trigger for Three.js.

`assets/js/main.js` contains only a one-line placeholder comment.

<task id="05-01-T2">
<title>Write main.js — GSAP ticker wiring + hero animation</title>

<read_first>
- assets/js/main.js (current placeholder)
- assets/js/scene.js (exports: init, resize, render — lines 1–111)
- index.html (canvas element id: `particle-canvas`, hero elements: `.hero__tagline`, `.site-header`, class `.brand-logo`)
- assets/css/base.css (block 6: `--bp-mobile: 768px`; reduced-motion block lines 121–126 — CSS side already handled)
</read_first>

<action>
Write `assets/js/main.js` with the following structure:

1. **Import scene.js** using a static module import (same CDN path as index.html Phase 4 had):
   ```
   import { init, resize, render } from './scene.js';
   ```

2. **Bootstrap function** that:
   a. Gets `canvas = document.getElementById('particle-canvas')`
   b. Checks WebGL availability (same pattern as Phase 4 index.html check — `canvas.getContext('webgl') || canvas.getContext('experimental-webgl')`)
   c. If no WebGL: `canvas.classList.add('hidden')` and return early
   d. Calls `init(canvas)` then `resize()`
   e. Adds `window.addEventListener('resize', resize)`
   f. Registers ScrollTrigger plugin: `gsap.registerPlugin(ScrollTrigger)`
   g. Wires GSAP ticker: `gsap.ticker.add(render)` — this replaces the rAF loop
   h. Calls the hero animation (see step 3)

3. **Hero animation** (ANIM-01) — runs inside the bootstrap function after ticker is wired:
   ```
   gsap.from('.hero__tagline, .brand-logo, .brand-name', {
     y: 30,
     opacity: 0,
     duration: 0.8,
     stagger: 0.15,
     ease: 'power2.out',
   });
   ```
   This targets `.hero__tagline`, `.brand-logo`, `.brand-name` — the hero headline and logo. Animation plays once on load (GSAP fromTo with no repeat = plays once by default).

4. **DOMContentLoaded guard** — same pattern as Phase 4:
   ```
   if (document.readyState === 'loading') {
     document.addEventListener('DOMContentLoaded', bootstrap);
   } else {
     bootstrap();
   }
   ```

Key constraint: `gsap` and `ScrollTrigger` are available as globals (loaded as UMD via CDN script tags before this module), not imported — do NOT add `import gsap from ...` or `import ScrollTrigger from ...`.
</action>
