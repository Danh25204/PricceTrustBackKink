# Plan 05-02: ScrollTrigger Animations — Cards, CTA, Floating Button

## Objective

Write all ScrollTrigger entrance animations in `assets/js/animations.js` and wire them into `main.js`. Covers service cards (ANIM-02), pricing cards (ANIM-03), contact CTA block (ANIM-04), and floating Telegram button slide-in (ANIM-05). All animations play exactly once (ANIM-06).

## Context

After Plan 05-01, `main.js` has GSAP registered and the hero animation. `animations.js` is still a placeholder. The DOM elements to animate:
- `.service-card` — 3 elements in `#services .services__grid`
- `.pricing-card` — 11 elements across `#backlink`, `#blog-comment`, `#entity`
- `#contact` — the contact CTA section
- `#cta-float` — the floating Telegram button (positioned `fixed`, bottom-right)

ScrollTrigger default behavior (no `repeat`) plays animations once when element enters viewport.

<action>
Write `assets/js/animations.js` with a single exported function `initScrollAnimations()`:

```
export function initScrollAnimations() {
  // ANIM-02: Service cards stagger fade-in from bottom
  gsap.from('.service-card', {
    y: 40,
    opacity: 0,
    duration: 0.6,
    stagger: 0.15,
    ease: 'power2.out',
    scrollTrigger: {
      trigger: '#services',
      start: 'top 80%',
      once: true,
    },
  });

  // ANIM-03: Pricing cards stagger fade-in + subtle scale
  gsap.from('.pricing-card', {
    y: 30,
    opacity: 0,
    scale: 0.97,
    duration: 0.5,
    stagger: 0.08,
    ease: 'power2.out',
    scrollTrigger: {
      trigger: '.pricing-card',
      start: 'top 85%',
      once: true,
    },
  });

  // ANIM-04: Contact CTA block scale 0.95 → 1.0
  gsap.from('#contact', {
    scale: 0.95,
    opacity: 0,
    duration: 0.6,
    ease: 'power2.out',
    scrollTrigger: {
      trigger: '#contact',
      start: 'top 80%',
      once: true,
    },
  });

  // ANIM-05: Floating Telegram button slides in from right after 3s
  gsap.fromTo('#cta-float',
    { x: 80, opacity: 0 },
    { x: 0, opacity: 1, duration: 0.5, ease: 'power2.out', delay: 3 }
  );
}
```

Key constraints:
- `once: true` on every ScrollTrigger ensures animations play exactly once (ANIM-06)
- `#cta-float` uses `gsap.fromTo` with `delay: 3` (not a ScrollTrigger — it's time-based per ANIM-05)
- Do NOT use `repeat: -1` or `yoyo` anywhere
- `gsap` and `ScrollTrigger` are globals — do NOT import them
</action>
